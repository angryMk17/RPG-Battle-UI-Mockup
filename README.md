# RPG-Battle-UI-Mockup
This repository is a mockup of an RPG fighting UI made in Scratch. not much else to say about it really, I'ts neat but I'm already making the step to convert to Godot. I just need this on my portfolio, hence I'm uploading it here.

It's obviously inspired by Deltarune and Undertale, but I made it a separate design for sure. All assets were made by me except for the parallax cloud png.

So, the text system, I remember working on this. I made it so that instead of just printing static text, I built a custom parsing system so I could format dialogue on the fly using these special characters:

'%' = Line break

'|' = Added pause (spam it for longer dramatic pauses)

'*' = Circles at the start of a paragraph

'\' = Slow text toggle (use it again to go back to normal speed, use for dramatic effect!)

You can check out the source code and play it directly on the released Scratch project here: https://scratch.mit.edu/projects/1222139539/
